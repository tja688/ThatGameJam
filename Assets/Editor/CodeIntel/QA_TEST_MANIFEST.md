# CodeIntel QA Test Manifest

## 1. 项目简介 / Project Overview

**CodeIntel** 是一款为 Unity 开发的插件，它作为 Unity 编辑器与 OmniSharp 之间的桥梁，通过 HTTP API 为外部 AI Agent 提供语义级代码索引与导航能力。它支持“跳转到定义”、“查找引用”以及“符号搜索”等功能，旨在帮助 AI 开发者更快捷地理解复杂的业务逻辑与三方库。

本项目 **ThatGameJam** 是一个基于 **QFramework** 架构开发的 Unity 2D 游戏。项目中集成了以下核心三方库：
- **DOTween**: 用于 UI 与物件动画。
- **UniTask**: 核心异步编程方案。
- **UniRx**: 响应式数据流。
- **Pixel Crushers (Dialogue System)**: 对话系统。
